PubChat

PubChat Guide

PubChat connects academic papers with public discussion threads on Bluesky.

What is PubChat?

PubChat gives each supported paper a canonical discussion page, a Bluesky discussion thread, and a stable URL that anyone can share.

Example:

https://pubchat.org/chat/arxiv/2601.22079

PubChat currently supports arXiv papers and DOI-based papers when public metadata APIs provide title, authors, year, and abstract.

How PubChat Works

1. Every paper has a canonical PubChat page

PubChat pages use canonical paper identifiers:

https://pubchat.org/chat/arxiv/<id>
https://pubchat.org/chat/doi/<doi>

Examples:

https://pubchat.org/chat/arxiv/2601.22079
http://pubchat.org/chat/doi/10.1093/restud/rdaa053

You can open a paper’s PubChat page by entering an arXiv ID, arXiv URL, DOI, or DOI URL on pubchat.org.

2. PubChat creates a Bluesky anchor post

When a paper is first viewed on PubChat, PubChat creates a Bluesky post containing the paper title, authors, year, and a link back to the PubChat page.

Example format:

“The Economics of No-regret Learning Algorithms” (2026) by Jason Hartline CC: PubChat

This becomes the root of the discussion thread.

3. Replies on Bluesky become the discussion

Anyone can reply to the anchor post on Bluesky. PubChat reads the Bluesky thread and renders it as a paper discussion page.

A Bluesky account is required to post. No PubChat account is required.

Import an existing Bluesky thread

PubChat discussions normally happen as replies to the PubChat anchor post. You can also attach an existing Bluesky thread to a paper page.

  1. Open the existing Bluesky thread you want to add.
  2. Copy the URL of the thread’s root post.
  3. Open the paper’s PubChat page.
  4. Click Start a new discussion on Bluesky.
  5. Reply to the PubChat anchor post with only the copied Bluesky post URL.

PubChat displays the existing thread inline on the paper page. Imported posts are shown with a lightly shaded background.

PubChat imports only the linked thread itself. Links inside imported threads remain ordinary links, and the same thread is expanded only once.
